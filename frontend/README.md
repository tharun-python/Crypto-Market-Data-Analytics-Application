# CryptoLens Frontend

React + Vite frontend for the CryptoLens dashboard.

## Run locally

```powershell
cd "c:\Users\ADMIN\Desktop\interview task\frontend"
npm install
npm run dev
```

## Notes

- The app expects the backend API to be running at `http://127.0.0.1:8000`
- Uses `axios`, `react-router-dom`, `recharts`, and `lucide-react`
- The price history page pulls data from `GET /history`
